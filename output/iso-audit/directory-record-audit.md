# Raw ISO directory-record audit

[codex-scripts/iso_directory_record_audit.py](../../codex-scripts/iso_directory_record_audit.py) reparses [archives/3301.iso](https://github.com/cicada-solvers/iddqd/blob/0e3789ad2949c62ea7fb9e3e00ded93df3b3ce07/2013/02/3301.iso) directly as bytes; it never mounts or executes the image. Full record fields, absolute offsets, sector tails, padding, system-use data, path tables, allocation intervals, and checks are in [output/iso-audit/directory-record-audit.json](directory-record-audit.json).

The primary volume descriptor reports 66,601 sectors of 2,048 bytes, matching the 136,398,848-byte image. Its L and M path tables parse identically and match the five reachable directories and parent indices. The root directory record is at absolute offset 32,924; the reachable directories are `/` at LBA 24, `/AUDIO` at 25, `/DATA` at 26, `/BOOT` at 27, and `/BOOT/ISOLINUX` at 28. All 25 directory records parse within their sector boundaries, and both-endian extent, data-length, volume-sequence, root, and path-table references agree.

The five directory-sector zero tails total 9,254 bytes and are entirely zero. Twelve required identifier-padding bytes are zero; no directory record has system-use bytes. The directory entries use only ordinary flags (`0x02` for directories and `0x00` for files); there are no hidden, associated, record-format, permission, reserved, or multi-extent flags. Extended attributes, interleaving, duplicate exact names, and duplicate names under uppercase/version/trailing-period normalization are absent. Each directory has one consistent `.` and `..` record.

The 11 file extents have 8,460 bytes of sector slack in total, all zero. Including the root directory, child directories, files, path-table sectors, and volume-descriptor sectors, no allocated sector intervals overlap. All record timestamps and volume-sequence values are valid. The parser reported zero anomalies, including no nonzero skipped bytes after a zero terminator.
