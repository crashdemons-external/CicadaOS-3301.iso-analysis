# Derived image container audit

This is a bounded structural audit of the two already-derived images, using only Python stdlib and bundled Pillow. It reads files only; it does not run `outguess`, XOR scripts, or any archive executable. Machine-readable detail and the reproducible audit script are [image-container-audit.json](image-container-audit.json) and [image_container_audit.py](../../codex-scripts/image_container_audit.py).

## [cicada-reproduced.png](cicada-reproduced.png)

The 15,330-byte PNG is 521×523, 8-bit grayscale+alpha (PNG color type 4, non-interlaced). All seven chunks (`IHDR`, `bKGD`, `pHYs`, `tIME`, two `IDAT`s, `IEND`) have valid CRCs. `bKGD` is grayscale 255; `pHYs` is 2835×2835 pixels/meter; `tIME` records 2012-12-31 23:37:39. The concatenated 15,207-byte IDAT zlib stream reaches EOF, has no unused or unconsumed input, decompresses to exactly 545,489 scanline bytes, and has no trailing file bytes after IEND. Row PNG filters occur 81 times as Sub (1), 392 as Up (2), and 50 as Paeth (4).

The alpha channel is completely opaque (all 255). Grayscale samples occupy only 0–7 (eight values, entropy 0.529 bits/pixel); grayscale LSBs are strongly biased (8,419 set among 272,483; entropy 0.199 bit). These statistics reflect the very dark low-range image and do not indicate a separate alpha payload. Deterministic contrast-stretched and grayscale bit-plane 0/1/2 previews are now emitted by the audit script as [cicada-png-contrast-preview-audit.png](cicada-png-contrast-preview-audit.png) and `cicada-png-bitplane-{0,1,2}-audit.png`; they are display aids, not payload recoveries. The repository preview checks show ordinary cicada structure, with no distinct message signal apparent. The archive README explicitly records the dimensions and gray+alpha mode and says the image seemed unremarkable and that its author found no steganography with many tools ([archives/neuroretransmit-cicada/2013/003-twitter/README.md:55–62](https://github.com/cicada-solvers/neuroretransmit-cicada/blob/b13600373d3400d75ec4208198019f3d92a304dd/2013/003-twitter/README.md)), but I found no explicit documentation of the measured 0–7 luminance range or 3-bit dynamic range in that README or the wiki export. So the numeric range is a newly recorded file property of an already-known image, not evidence of a newly solved payload. The image is byte-identical (SHA-256 `a771856f…6c3edb`) to [archives/neuroretransmit-cicada/2013/003-twitter/decoded.png](https://github.com/cicada-solvers/neuroretransmit-cicada/blob/b13600373d3400d75ec4208198019f3d92a304dd/2013/003-twitter/decoded.png). That equality establishes provenance/identity with this archived derived image, not an absence of all possible steganography.

## [gematria-reproduced.jpg](gematria-reproduced.jpg)

The 64,167-byte JPEG is baseline SOF0, 598×842 RGB, one scan. The marker walk finds only JFIF APP0, two quantization tables, SOF0, four Huffman tables, SOS, and EOI. There are no APP1/EXIF or COM segments, no malformed marker/length boundaries, and no trailing bytes after EOI. Pillow reports only JFIF 1.01 with unitless 1×1 density and no EXIF tags.

It is byte-identical (SHA-256 `d4736b09…580eb35d`) to [archives/archive2/assets/2013/gematria-primus.jpg](https://github.com/cicada-solvers/The-Complete-Cicada3301-Archive/blob/c3127e0e9eb5afbb582d37988d6369fe38429238/assets/2013/gematria-primus.jpg). Its decoded pixels are exactly equal to the distinct archived re-encodings [archives/archive2/2013/additional images/Testout.jpg](https://github.com/cicada-solvers/The-Complete-Cicada3301-Archive/blob/c3127e0e9eb5afbb582d37988d6369fe38429238/2013/additional%20images/Testout.jpg) and [archives/archive2/2014/additional images/Testout.jpg](https://github.com/cicada-solvers/The-Complete-Cicada3301-Archive/blob/c3127e0e9eb5afbb582d37988d6369fe38429238/2014/additional%20images/Testout.jpg) (and `assets/2014/stage04/gematria-primus.jpg`); these copies have different JPEG bytes but zero decoded channel difference. [archives/archive2/assets/2013/testout.jpg](https://github.com/cicada-solvers/The-Complete-Cicada3301-Archive/blob/c3127e0e9eb5afbb582d37988d6369fe38429238/assets/2013/testout.jpg) is another byte-distinct, pixel-identical copy. This is a specific pixel/metadata/container check, not a general steganographic proof.

The archive contains signed OutGuess transcript text at [archives/archive2/2013/additional docs/signed messages/gematria-primus.jpg.out.txt](https://github.com/cicada-solvers/The-Complete-Cicada3301-Archive/blob/c3127e0e9eb5afbb582d37988d6369fe38429238/2013/additional%20docs/signed%20messages/gematria-primus.jpg.out.txt) and the corresponding binary `.out` artifact under [archives/archive2/assets/2013/](https://github.com/cicada-solvers/The-Complete-Cicada3301-Archive/blob/c3127e0e9eb5afbb582d37988d6369fe38429238/assets/2013/). The preserved Twitter reconstruction README states that the completed `gematria.jpg` was read with OutGuess to produce `gematria.jpg.asc` ([archives/neuroretransmit-cicada/2013/003-twitter/README.md](https://github.com/cicada-solvers/neuroretransmit-cicada/blob/b13600373d3400d75ec4208198019f3d92a304dd/2013/003-twitter/README.md), discussion around lines 62–70), and includes the signed transcript. This audit did not run OutGuess or independently validate that transcript’s signature. Contemporary IRC lines 4521–4523 in [archives/archive2/2013/additional docs/logs/all cosmos posts from 7th on the 761 song - full log.txt](https://github.com/cicada-solvers/The-Complete-Cicada3301-Archive/blob/c3127e0e9eb5afbb582d37988d6369fe38429238/2013/additional%20docs/logs/all%20cosmos%20posts%20from%207th%20on%20the%20761%20song%20-%20full%20log.txt) likewise describe the completed image yielding a whitespace-heavy signed message; this is corroboration of historical reporting, not independent cryptographic verification.

## Limits

The audit checked PNG chunk framing/CRCs, zlib stream termination and scanline accounting, standard PNG channels/LSBs, and JPEG marker framing/metadata/trailing bytes. It did not exhaustively test steganographic algorithms, inspect every frequency-domain representation, validate PGP signatures, or establish that no other copy/input has hidden data. No extra preview was generated because the inspected alpha channel is constant and the grayscale LSB plane is highly biased rather than showing a distinct candidate signal.
